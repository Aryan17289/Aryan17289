## About

I turn messy data into answers people can act on. I work mostly in SQL and Python, build dashboards in Power BI, and apply machine learning where it earns its place.

Most of what I build here is end to end: raw files, a clean database, analysis, then a dashboard or API someone else can use without me explaining it.

```yaml
Right now:
  Working on:  Analytics projects with recruiter-ready dashboards
  Learning:    Advanced Power BI and DAX, cloud pipelines on AWS
  Looking for: Data Analyst and Business Intelligence roles
```
